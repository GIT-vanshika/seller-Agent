# AI Purchase Confidence & Deal Agent

An AI-powered agent designed to boost purchase confidence, evaluate deal terms, and assist with purchase decision-making.

## Development Status

> **Current Phase**: Day 1 — Foundation Setup
> 
> The project folder structure has been established with dedicated directories for backend services, frontend UI, and local data storage.

## Project Structure Overview

- `backend/`: Python + FastAPI application for core business logic, APIs, and AI processing.
- `frontend/`: React / Next.js user interface.
- `data/`: Local storage for datasets, mock schemas, or temporary data files.
